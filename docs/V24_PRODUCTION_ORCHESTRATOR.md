# Historical POV Studio V24 — Production Orchestrator

V24 changes the app from a set of manual tools into a recoverable production pipeline.

## Main rule

**Free-first production:**

- Voice generation is the only step allowed to use a paid/API provider.
- Image production is local/free: V24 creates approved placeholder PNGs and prompt text files.
- Music/SFX is local/free: V24 creates approved silent WAV beds and cue text files.
- Orchestration, director reports, recovery, budget forecast, assembly timeline and FFmpeg scripts are local/free.

Paid voice is still blocked by `.env` unless:

```env
ALLOW_PAID_GENERATION=true
MAX_BUILD_COST_USD=...
```

## New UI tab

Open:

`Control → V24 Orchestrator`

Buttons:

- **Rebuild Plan** — creates durable jobs in the project database.
- **Run V24 Pipeline** — runs all pending safe/local tasks. Voice is skipped unless you tick **Also run voice generation**.
- **Export Director Report** — creates `production_reports/v24_director_report.json`.
- **Write Recovery Snapshot** — creates `production_recovery/manual_snapshot.json`.
- **Export Budget Forecast** — creates `production_reports/v24_budget_forecast.json`.

## Job statuses

- `pending` — ready to run.
- `running` — currently executing.
- `waiting` — blocked by dependency, usually voice.
- `blocked` — manual story/script work required.
- `retry` — failed but can be retried.
- `failed` — stopped after max attempts or blocked by cost guard.
- `completed` — finished.

## Dependency behavior

For each block:

1. Story must exist.
2. Voice should be approved for real timing.
3. Image placeholder/prompt can be created locally.
4. Music cue/silent bed can be created locally.
5. Assembly exports once all required assets are ready.

If voice is missing and **Also run voice generation** is disabled, the job remains `waiting`. This is intentional because voice is the only step that may cost money.

## Version goal

V24 is not a UI-polish version. It adds the missing production brain:

- durable jobs
- dependencies
- resume/recovery snapshots
- free local image/music placeholders
- budget forecast
- offline director report
- assembly build integration
