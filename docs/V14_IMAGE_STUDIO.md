# v14 Image Studio Test

1. Run `run_studio_v14.bat`.
2. Select `B001`.
3. Open `Image Studio`.
4. Click `Import Image` or drag/drop a PNG/JPG/WebP.
5. Confirm file is copied to:

```text
projects/cannae_001/assets/images/B001/v001.png
```

6. Import another image.
7. Confirm `v002`.
8. Select an image and click `Approve Selected`.
9. Confirm `approved.png` exists and B001 image status becomes approved.
10. Restart app and confirm image status persists.
