# V31 Execution + Preview Package

V31 turns V28/V29/V30 plans into an executable editing package.

Adds:

- Canonical asset library (`production/asset_library.json`)
- Real visual slot folders under `assets/visual_slots/VIS###/`
- Real scene music folders under `assets/scene_music/S###/`
- Prompt/cue files and README files for every slot/scene
- Placeholder `approved.txt` assets so timeline and preview can run without final media
- Compatibility pointers for older block image/music UI
- Full timeline preview HTML/CSV over all blocks
- Full assembly manifests over all blocks, not demo subset
- V31 CapCut import CSV
- V31 episode package
- V31 health report

Policy:

- Voice = block based
- Visuals = visual slot based
- Music = scene based
- Final MP4 rendering remains a future step
