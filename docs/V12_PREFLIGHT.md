# v12 Preflight

At home:

1. API Settings
2. Paste `DASHSCOPE_API_KEY`
3. Paste `QWEN_WORKSPACE_ID`
4. Region: `singapore` or `beijing`
5. TTS Instruct Model: `qwen3-tts-instruct-flash`
6. Save `.env`
7. Restart app
8. Check Config
9. Run Tiny Smoke Test

Tiny test text:

